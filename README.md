One letter for your day: **B** — bonkers. A deterministic Python 3.13 program (standard library only, no network) that writes exactly one character, the letter B, to `/output/entry.txt`. B stands for "bonkers": a day that went completely off the rails — vivid, funny, and true.

## Run it

```sh
python3 main.py
```
